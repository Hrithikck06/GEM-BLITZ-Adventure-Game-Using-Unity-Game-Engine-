# GEM-BLITZ Adventure Game Using Unity Game Engine
Gem Blitz is a 3D action-adventure game developed using the Unity Game Engine and C#. The game challenges players to collect gems, avoid enemies, maintain health, and reach the safe zone to complete the level.

Features

* Third-person player movement
* Mouse-controlled third-person camera
* Gem collection system
* Enemy interactions and health reduction
* Score management system
* Safe zone activation mechanism
* Win and lose conditions
* Real-time UI for score and health
* Audio feedback effects

Technologies Used

* Unity Game Engine
* C#
* Visual Studio Code
* Unity Physics System
* TextMesh Pro

Gameplay

1. Control the player using keyboard inputs.
2. Use the mouse to rotate the camera and view the environment.
3. Collect all gems scattered around the map.
4. Avoid enemies to preserve health.
5. Activate the safe zone by completing the objective.
6. Reach the safe zone to win the game.

Project Structure

* Assets/ - Game assets, scripts, scenes, and prefabs
* Packages/ - Unity package dependencies
* ProjectSettings/ - Unity project settings
